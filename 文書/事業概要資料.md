# はるとの事業・プロジェクト概要

## 1. 美容福祉団体 Re-Palette
- **理念**: 美容をすべての人の自信を作るインフラへ
- **ビジョン**: 美容を用いた社会復帰支援モデルの構築を通じて、多くの人に自信を届ける
- **活動**: コミュニティや団体を通じた社会的支援と美容アプローチの統合

## 2. テック・AI関連プロジェクト
- **FRIDAY-Mark3 / ARQO / NEWTONE**: 各種AIプラットフォームおよびエージェント基盤の開発
- **スマートリング構想**: スマホとテザリングし、AIを直感的に操作できるウェアラブルデバイスの企画（初期フェーズ）

## 3. AIカンパニー事業
- 48名のAI社員を擁する組織の運営と統括
- 各種プロジェクトの自動化および事業化の推進
