# 株式会社化に向けた事前準備チェックリスト

## 1. 事業の整理と方向性の明確化
- 法人化する事業の明確化（Re-Paletteやその他の事業）
- 収益モデルとマネタイズの具体的な設計
- ターゲット顧客と提供価値の言語化

## 2. 定款の作成・基本事項の決定
- 商号（会社名）の決定
- 本店所在地の決定
- 発行可能株式総数と資本金の額の決定
- 事業目的（定款に記載する事業内容）の洗い出し

## 3. 体制とルールの整備
- 共同創業者やメンバーがいる場合の役割分担と株主構成の検討
- 資金計画（設立費用や当面の運転資金の確保）
- 銀行口座や会計ツールの準備

## 4. 各種手続きのスケジュール確認
- 行政手続き（登記申請、税務署への届出など）の段取り
- 【要確認】未成年（高校生）起業における親権者の同意や手続きの確認
